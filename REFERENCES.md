# References

Compiled 2026-08-13, ahead of making this repository public, in direct
response to a real point: **this project is not claiming novel food
science.** Every safety threshold, physical constant, and technique claim
in `data/*.json` and `src/*.ts` is either a standard reference value, a
government/regulatory food-safety standard, or a specific published study —
never invented for this repo. What *is* original here is the executable
schema/engine representation (`Entity`/`State`/`Action`/`Parameter`, the
HACCP enforcement in `engine.ts`, the D/z-value thermal model applied the
way it is) — not the underlying culinary or food-safety facts themselves.

This file is generated by cross-checking every `citation`/`source` field
actually present in `data/entities/*.json`, `data/actions/*.json`,
`data/ccps/*.json`, `data/heat-sources/*.json`, and `src/*.ts` (not
retyped from memory — see the extraction command in this file's own git
history if you want to re-run the check), plus everything researched live
via `WebSearch`/`WebFetch` this session and written into a real file. Each
entry states **where** it's used and **how confident** this repo is,
matching `CitationSchema`'s own `confidence` vocabulary
(`standard_reference` / `commonly_cited_unverified`) rather than presenting
everything as equally certain.

## Food-safety / regulatory standards

The actual legal/regulatory basis for every HACCP threshold this repo
enforces (`data/ccps/*.json`, `src/thermal.ts`) — not house numbers.

- **USDA FoodSafety.gov, "Safe Minimum Internal Temperature Chart"** —
  https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperature
  — egg dishes: 160°F/71°C instantaneous. Used in `data/ccps/egg_cooking.json`
  (`instantaneousC`) and `egg_pasteurization_raw.json`.
- **FDA Food Code §3-401.11(A)** — the 145°F/63°C-for-15-seconds
  time-temperature-equivalence figure for shell eggs prepared for immediate
  service. Used in `data/ccps/egg_cooking.json` (`heldC`/`heldSeconds`).
- **FDA Food Code §3-603.11** — the provision explicitly permitting
  eggs cooked to order with a runny yolk as a disclosed "increased risk"
  practice, not a banned one. Basis for `egg_cooking.json`'s
  `advisoryOnly: true` and `engine.ts`'s human-vs-autonomous `SafetyPolicy`
  distinction (`ENGINE_INVARIANTS.md` #11).
- **9 CFR Part 590 / FDA egg products standards** — 60°C/140°F for 3.5
  minutes (210s) as the regulated minimum pasteurization for liquid whole
  egg product. Used in `data/ccps/egg_pasteurization_liquid.json`.
  Confidence: `commonly_cited_unverified` for the yolk-specific case —
  `egg_pasteurization_liquid.json` itself flags that the exact regulated
  figure for separated yolk alone (vs. whole liquid egg) hasn't been
  independently verified against the primary text.
- **In-shell pasteurization (57°C for ~65 minutes)** — a commonly-cited
  food-science/extension figure, the process popularized academically at
  Kansas State University and used commercially (e.g. Davidson's Safest
  Choice eggs). Used in `data/ccps/egg_pasteurization_raw.json`. Confidence:
  `commonly_cited_unverified` — the file itself flags that the exact
  published minutes haven't been independently verified against a primary
  source, and real commercial process parameters vary/are sometimes
  proprietary.
- **Stumbo's thermal death time model (D-value/z-value kinetics)** — the
  standard textbook thermobacteriology model the FDA Food Code's own
  multi-point tables were themselves derived from; not a novel formula.
  Implemented as `requiredHoldSeconds` in `src/thermal.ts`, with its own
  stated validity condition (product must reach medium temperature quickly
  — thin/liquid/well-mixed, no insulating barrier).

## Physical constants & composition data

- **USDA FoodData Central** (fdc.nal.usda.gov) — raw potato, whole egg, egg
  white, egg yolk, garlic, black pepper, and (closest match) chili flakes
  composition figures. Used across `data/entities/*.json`'s
  `composition.citation`. Confidence: `standard_reference` for the direct
  matches, `commonly_cited_unverified` for chili_flakes (no generic
  "crushed dried chili flake" FDC entry exists; red/cayenne pepper used as
  the closest standard entry).
- **Choi & Okos (1986), "Effects of Temperature and Composition on the
  Thermal Properties of Foods"** — the standard predictive food-engineering
  model for deriving thermal conductivity/density/specific heat from
  composition. Used in `potato.json`/`egg.json`/`garlic.json`'s
  `thermophysical.citation`. Confidence: `standard_reference`, but flagged
  in each file as recalled-as-typical-range values, not re-derived from the
  model against each ingredient's actual composition this session.
- **CRC Handbook of Chemistry and Physics** — standard reference values for
  sodium chloride (density, melting/boiling point) and for water (density,
  boiling point, specific heat at 1 atm). Used in `salt.json`/`water.json`'s
  `thermophysical.citation`. Confidence: `standard_reference`.
- **IUPAC standard atomic weights** (Na 22.98977, Cl 35.453) — used to
  compute NaCl's exact sodium mass fraction (39.337%) for `salt.json`'s
  `composition.citation`, rather than looked up from a food-composition
  table. The one figure in this repo that's exactly derivable rather than
  empirical, since table salt is essentially pure NaCl by definition.
- **International Olive Council (IOC) trade standard density range**
  (~0.910–0.916 g/cm³ at 20°C for olive oil) — used in `oil.json`'s
  `thermophysical.citation`, since every recipe in this repo naming "oil"
  is Spanish/Mediterranean and implicitly olive oil. Confidence:
  `commonly_cited_unverified` — this repo has not looked up the current IOC
  document directly.
- **U.S. Department of Energy consumer cooktop-efficiency guidance** and
  commonly-cited consumer appliance spec figures — used in
  `data/heat-sources/gas.json`/`vitro.json`'s `citation` for typical
  burner/hob power and thermal-efficiency ranges. Confidence:
  `commonly_cited_unverified`.

## Culinary technique & food science literature

- **Kalogianni & Smith, "Effect of frying variables on French fry
  properties," *International Journal of Food Science and Technology*
  48(4):758–770 (2013)** — https://doi.org/10.1111/ijfs.12024 — peer-reviewed
  physics behind `data/actions/fry.json`'s `oilTempC` and
  `data/actions/par-fry.json`'s two-temperature design (water removal and
  oil uptake are not simply linked; most property change happens in the
  first 1–2 minutes; crust thickness plateaus despite continued heat
  penetration). Verified via direct lookup 2026-08-13. Confidence:
  `standard_reference` (peer-reviewed).
- **Thermoworks, "Golden, Crisp French Fries"** —
  https://blog.thermoworks.com/golden-crisp-french-fries/ — the concrete
  double-fry practitioner numbers (163°C/4–5min par-fry, 191°C/~3min finish,
  ≥10min rest between stages, ~6mm/¼" stick thickness). Used in
  `data/actions/par-fry.json`'s `sourcesNote`/`restNote`/`thicknessNote`.
  Confidence: `commonly_cited_unverified` — a well-regarded food-science-literate
  source, not itself peer-reviewed.
- **MDPI, "Non-Destructive Evaluation of Physicochemical Properties for Egg
  Freshness: A Review" (2024)** —
  https://www.mdpi.com/2077-0472/14/11/2049 — and the albumen-viscosity study
  it corroborates —
  https://www.sciencedirect.com/science/article/pii/S0032579119424632 — the
  ovomucin-network-breakdown mechanism behind `data/entities/egg.json`'s
  `fresh`/`aged` tags (why a fresh egg's white holds its shape when fried
  and an older one spreads). Verified via direct lookup 2026-08-13.
- **J. Kenji López-Alt, Serious Eats "The Food Lab" egg-timing guide** —
  the source for `src/egg-doneness.ts`'s `EGG_BOIL_DONENESS` soft/medium/hard
  seconds ranges. Confidence: `commonly_cited_unverified` — not verified
  against a primary source; internally cross-checked instead against
  `data/recipes/soft-boiled-egg.json`'s pre-existing 390s choice, which
  falls inside the cited "soft" range.
- **Egg-boiling technique guides converging on the same recommendation**
  (e.g. J. Kenji López-Alt/Serious Eats "The Food Lab"; America's Test
  Kitchen) — lowering an egg into the water via a slotted spoon/skimmer,
  rather than dropping it, is standard advice specifically to avoid a
  mechanical-impact shell crack against the pot or another egg. Used in
  `data/actions/boil.json`/`simmer.json`'s `placementMethod` parameter
  (`lowered_with_spoon`). Confidence: `commonly_cited_unverified` — same
  tier and same source family as the entry above, not independently
  re-verified this session.
- **Harold McGee, *On Food and Cooking*** — general food-science reference
  used for: egg white/yolk coagulation temperature ranges
  (`data/ccps/egg_cooking.json`'s `coagulationReferenceC`), typical
  shallow-frying/Maillard temperature bands (`fry.json`'s `heatLevel`
  note), and open-fire cooking efficiency framing
  (`data/heat-sources/wood_fire.json`). Confidence: `commonly_cited_unverified`
  — recalled, not re-checked against the text directly this session.
- **Eric Block, *Garlic and Other Alliums: The Lore and the Science*
  (Royal Society of Chemistry, 2010)** — the standard reference on Allium
  organosulfur chemistry (alliinase/alliin→allicin conversion on cell
  rupture). Used in `data/entities/garlic.json`'s `flavorChemistryNote`.
  Confidence: `commonly_cited_unverified` — recalled as well-established
  biochemistry, not re-verified against the text directly this session.

## Discussed, informs design reasoning, not yet embedded in any data file

- **Di Lorenzo & Di Maio, "Periodic cooking of eggs," *Communications
  Engineering* (Nature Portfolio), Feb 6 2025** —
  https://www.nature.com/articles/s44172-024-00334-w — the alternating
  100°C/30°C egg-cooking study discussed at length in conversation (see
  `ROADMAP.md`'s "Heat as a shared, time-varying property of a PLACE" entry
  for the design implications). Unlike every source above, this one is
  **not** cited from any `data/*.json` or `src/*.ts` file — the technique it
  describes can't be represented by this engine yet (needs the unbuilt
  multi-bath/time-varying-place mechanism), so nothing here claims to
  implement it. Listed for the same transparency reason as everything
  else: it genuinely informed this repo's design discussion, even though no
  code or data currently encodes it.

## What's original vs. what's cited

To close the loop on why this file exists: the **facts** above (a
Salmonella kill threshold, water's boiling point, an egg's albumen
chemistry, French-fry frying kinetics) are not this project's contribution
— they're standard science and regulation, cited as such. This project's
actual contribution is representing those facts as an **executable,
falsifiable schema** (Zod-validated JSON + a deterministic TypeScript
engine) that a program can enforce, rather than as prose a human has to
re-derive correctly every time — see `CLAUDE_DEV_CTX.md` for that framing
in full. Being explicit about which is which matters more once this
becomes public than it did in a private working repo.
