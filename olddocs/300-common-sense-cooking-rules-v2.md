# 300 Common-Sense Cooking Rules

A practical collection of simple cooking truths, physical constraints, state changes, and everyday kitchen knowledge.

The principle is simple: **if an action does not make physical or culinary sense for an ingredient in its current state, it should not be available.**

These rules are deliberately written in a way that can be translated into a cooking simulation or knowledge system.
